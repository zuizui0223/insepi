# V11 pre-result freeze — contradiction-guided development

V11 tests a development method, not a new sensing allocation score.

## Frozen question

Does preserving separate biological-evidence and observability-risk hypotheses, plus protected random audit, improve localisation of hidden failure mechanisms and selection of transferable repairs relative to event-only, observability-only, or early scalar-fusion development?

## Historical boundary

Locked V7 has already failed its preregistered allocation gate (claim level C). V11 does not retune, rescue, reinterpret, or replace V7. V6 remains 50% exploration / 10% evidence / 40% observability / 0% disagreement. V10 remains a separate real-pixel transfer generation.

## Four latent diagnostic states

The controlled truth axes are biological event yes/no × observation disturbance yes/no. Observer outputs remain distinct and are thresholded only for diagnostic state labels:

1. evidence high / observability low;
2. evidence low / observability high;
3. both high;
4. both low.

The fourth state is intentionally ambiguous: quiet and shared blind spots can look identical without independent audit. Therefore contradiction alone is never treated as truth.

## Fair strategy comparison

Every strategy receives exactly the same six probes, in the same order, and the same protected random-audit assignments. Strategies differ only in which representation is retained:

- event-only: evidence channel;
- observability-only: observability channel;
- early scalar fusion: 0.5 evidence + 0.5 observability;
- contradiction-guided: both channels, four-way diagnostic state, and audited low-low shared-miss evidence.

## Transfer rather than memorisation

Nearest-centroid models are fitted only on development mechanism subtypes:

- event contrast loss;
- glare risk blind spot;
- occlusion shared blind spot;
- clean control.

Final scoring uses different held-out subtypes:

- event scale shift;
- shadow risk blind spot;
- blur shared blind spot;
- independent clean control.

No hyperparameter search is permitted.

## Primary outcomes

- held-out failure localisation accuracy;
- wrong-module intervention rate;
- shared-blind-spot discovery rate;
- no-fault false-intervention rate;
- experiments to stable falsification;
- held-out repair positive-transfer rate;
- held-out repair relative loss reduction.

The repair test replays the same held-out episode/noise with the predicted module intervention. Wrong repairs are allowed to hurt; they are never clipped into apparent improvements.

## Claim ceiling

Claim levels A–D are fixed in `benchmarks/v11_contradiction_development_protocol.json`. V11 can support a development-method claim only; it cannot establish statistical independence, field biological accuracy, direct disagreement allocation, universal quotas, or replace a physical held-out V12 validation.

The protocol was committed before the first V11 benchmark result is generated.
